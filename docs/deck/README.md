# Presentation

`SetuHaul-Dock-Desk.pptx` — ten slides, 16:9, speaker notes on every one.

Running order: the failure → the lane boundary → the ten predicates and the oracle → the race
test → the model comparison → why there is no retrieval → the case with no good answer → the live
latencies → the two defects only a browser found → what is proved and what is not.

The notes carry the things worth saying out loud and not putting on a slide: the three bugs the
independent oracle exposed, why the intent-accuracy failure was a labelling problem rather than a
model problem, and the correction about reserved concurrency.

Built from `scripts/` output and the measurements in `docs/07-EVALUATION.md` — every number on a
slide appears in a file in this repository. The deck closes on the limits rather than the wins,
because the honest column is what makes the rest credible.
